# 🧩 MiniCRM — персональная система управления проектами

**MiniCRM** — это лёгкое и понятное веб-приложение для фрилансеров, дизайнеров, студентов и небольших команд, которым не нужны громоздкие CRM-системы.  
Главная идея — _«ничего лишнего, только работа»_.

---

## 🚀 Возможности

- **Клиенты** — хранение контактных данных, заметок, истории проектов.  
- **Проекты** — карточки с названием, заказчиком, бюджетом, статусом и сроками.  
- **Задачи** — подзадачи, приоритет, дедлайны.  
- **Финансы** — отображение стоимости и статуса оплаты.  
- **Kanban-доска** — визуальное управление проектами (drag-and-drop).  
- **Поиск и фильтрация** — быстрый доступ к нужным элементам.  

---

## 💡 Особенности

- Современный **интерфейс в тёмной теме**, основанный на чистом UI/UX-дизайне.  
- Удобный **drag-and-drop** функционал (Kanban-доска).  
- Минимум лишнего кода — чистая архитектура **Django + HTML/CSS/JS**.
